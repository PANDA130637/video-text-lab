# 视频质量评估原型

## 目的

视频生成系统除了文本语义匹配，还需要检查相邻帧是否稳定。项目新增了一个不训练大模型的评估入口：复用冻结 CLIP 的帧特征和文本特征，同时输出文本一致性、相邻帧稳定性、闪烁比例和一个透明的综合分数。

这不是经过人类偏好校准的感知质量模型。它的作用是提供可重复的诊断和扰动对照，帮助定位生成结果中的明显问题。

## 指标

- `alignment_mean`：每帧视觉特征与 prompt 文本特征的平均余弦相似度；
- `alignment_p10`：帧级语义相似度的第 10 百分位，观察局部语义掉点；
- `temporal_adjacent_cosine`：相邻帧特征余弦相似度均值；
- `temporal_adjacent_std`：相邻帧相似度的波动；
- `flicker_rate`：相邻帧余弦相似度低于阈值的比例，默认阈值为 0.85；
- `quality_score`：`100 * (0.65 * alignment_score + 0.35 * stability_score)`，其中两个子分数把余弦相似度线性映射到 `[0, 1]`。

综合分数是工程诊断分数，不应直接当作人类质量判断或模型训练目标。平滑但语义错误的视频可能得分较高，快速且合理的动作也可能被稳定性项惩罚。

## 运行

先准备任意 CLIP 特征缓存，再执行：

```powershell
python run.py quality --cache data/kth/features_8f.npz --output runs/kth-quality --split test
```

输出包括 `quality.json`、`quality.csv`、`quality.md` 和离线 `quality.html`。命令还会进行两个固定扰动对照：随机打乱帧顺序，以及从另一段视频交替替换帧的跨视频闪烁扰动。

## KTH 子集结果

在 27 段测试视频上，干净输入的平均综合分数为 74.23，bootstrap 95% 区间为 74.03–74.43；相邻帧余弦均值为 0.9397，闪烁比例为 0.021。按动作类别分组，boxing、handclapping、handwaving 的平均分分别为 73.77、74.43、74.50。跨视频交替替换帧后，相邻帧余弦降到 0.8743，闪烁比例升到 0.339，综合分数降到 73.06。随机打乱帧的综合分数几乎不变，说明这个原型主要测量语义一致性和局部稳定性，不能独立证明动作顺序理解。

公开结果见 [质量评估报告](../reports/kth-quality/quality.html)。下一步若用于生成模型选择，应增加不同生成模型的候选视频，并用人工成对偏好标注校准权重和阈值。
