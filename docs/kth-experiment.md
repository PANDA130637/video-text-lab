# 第一轮真实视频实验

本实验已在本机 CPU 完成。它使用真实录制的人体动作视频，将类别标签改写成固定英文描述，验证低算力视频文本检索流程。

## 数据与协议

- 官方数据源：https://www.csc.kth.se/cvap/actions/
- 使用 boxing、handclapping、handwaving 三类，且只取 d1 场景的整段 AVI。
- 共 75 段、25 人；train/val/test 分别为 24/24/27 段，对应 8/8/9 人。
- 人物划分来自官方 `00sequences.txt`，同一人所有动作均在同一集合。
- 通过 HTTP Range 只取选定视频，传输约 160.53MB；每段保留 SHA-256，解压校验 ZIP CRC。
- 下载清单、许可说明、原始划分文件位于 `data/kth/`。数据仅供非商业使用；引用 Schuldt、Laptev、Caputo，ICPR 2004。
- 文本是类别模板，不是人工逐段撰写的丰富描述。没有顺序对照标注，不报告动作顺序准确率。

这不是 KTH 全部六类、四场景或官方子序列基准，不能把数值与其论文直接比较。

## 模型与控制

冻结官方 CLIP ViT-B/32，每段均匀取 8 帧，缓存 512 维特征；本机提取本批特征约 34.95 秒，权重已在本地。

比较完全冻结的 CLIP、mean＋投影、MLP＋投影和 GRU＋投影。MLP 先平均池化，不利用帧序；其 129,263 个参数与 GRU 的 129,472 个参数相差约 0.16%，控制容量因素。

训练预先固定为 40 轮、学习率 0.003、batch size 32、种子 17/42/123；所有训练完成后才计算测试结果。检查点只由验证集选择。协议在运行前写入 `runs/kth-8f/protocol.json`。

## 实际结果

主指标为测试视频→文本 Recall@1，三类候选下相当于按类别文本进行匹配。三个训练种子使用相同划分，标准差只反映训练随机性。

| 方法 | R@1 均值 | 说明 |
|---|---:|---|
| 冻结 CLIP 平均池化 | 33.3% | 无训练 |
| 冻结 CLIP 中间单帧 | 37.0% | 无训练 |
| mean＋投影 | 69.1% | 3 个种子 |
| MLP＋投影 | 72.8% | 3 个种子，近似匹配 GRU 参数量 |
| GRU＋投影 | 75.3% | 3 个种子 |

GRU 相对 MLP 约高 2.5 个百分点，但测试集只有 27 段、9 个独立人物，不能据此宣称稳定的时序优势。训练后的提升也可能包含对三类动作及拍摄分布的适配，不能外推到开放词汇或复杂场景。

完整结果、打乱帧诊断、各运行的验证记录及固定种子误检样例位于 `runs/kth-8f/`。

## 复现

在项目目录执行：

```powershell
python run.py prepare-kth
python run.py extract --manifest data/kth/manifest.csv --cache data/kth/features_8f.npz --encoder clip --frames 8 --threads 4 --offline
python run.py benchmark --cache data/kth/features_8f.npz --output runs/kth-8f-repeat
```

为保留原始证据，benchmark 拒绝覆盖非空结果目录。请为新运行选择新名称。

## 下一项有价值的实验

在新的实验协议中比较不同帧数和跨场景泛化，尽量扩大独立测试来源；不能根据本轮测试结果反复调参再把同一测试集当作全新验证。若研究动作先后关系，应另外准备真实 A→B / B→A 视频及明确标注。

可以据实描述为：实现了冻结 CLIP 特征上的低算力动作文本检索，完成按人物隔离的数据划分、参数量匹配对照、多种子实验和失败分析。它尚不构成视频生成模型或开放域视频理解的研发经历。
